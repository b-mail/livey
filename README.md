# Livey — 라이브 데모 수정 에이전트

2시간 해커톤 프로토타입. 화면에 떠 있는 라이브 데모를 채팅으로 수정 요청하면,
**서로 다른 해석의 A안·B안**을 격리된 샌드박스 2대에서 동시에 만들어 URL로 돌려준다.

## 실행

```bash
cd live-demo-agent
pip install -r requirements.txt
python orchestrator.py
# → http://localhost:8787
```

## 화면 구성 (Vercel 대시보드 스타일)

- **전체 화면 = 데모 슬롯** — 단일 HTML 파일을 **드래그 앤 드롭**(또는 클릭 선택)하면
  `/api/demo`로 등록되어 이 자리에 라이브 데모로 로드된다. 새로고침하면 지워진다.
- **우측 = AI 채팅** — 수정 요청을 자연어로 입력. 채팅 안에서 A안·B안의
  단계 진행(변형 생성 → 샌드박스 기동 → 서버 실행 → 준비 완료)이 표시된다.
- **생성 완료 후** — 상단 중앙에 `[원본 · A안 · B안]` 내비게이션이 나타난다.
- **A안/B안 선택 시** — 하단에 AI의 자연어 설명 패널이 열리고 데모는 축소된다.
  **위로 스크롤**하면 설명이 플로팅 카드로 접히며 데모가 전체화면이 된다.
  (아래로 스크롤하거나 플로팅 카드를 클릭하면 다시 도킹)

## 구조

```
orchestrator.py      # FastAPI + asyncio.gather, A/B 레인 병렬 실행
static/index.html    # 콘솔 (데모 슬롯 + 채팅 + 내비게이션 + 설명 패널)
static/livey-logo.png# Livey 로고
variants/1/{a,b}.html  # 1번째 요청 — A안 파이 차트 / B안 도넛 차트
variants/2/{a,b}.html  # 2번째 요청 — A안 파트너 칩 필터 / B안 툴바 필터+합계 행
```

## 모드

- **mock (기본)** — 변형을 로컬에서 서빙하고 단계 진행을 시뮬레이션. 키 없이 즉시 동작.
- **daytona** — `DAYTONA_API_KEY` 설정 시 진짜 샌드박스를 띄운다
  (`deploy_daytona()` — 레퍼런스 구현, 행사장에서 가장 먼저 검증할 것).

LLM 연동은 `generate_variant()` 함수 하나만 교체하면 된다
(원본 HTML + 요청 + 프롬프트 스타일 → 수정된 HTML).
